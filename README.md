# Ahamed Anas | Portfolio 🚀

Welcome to my personal portfolio! This project showcases my skills, experience, and the projects I've built as a Full-Stack Developer.

## 🌟 Overview

This is a modern, responsive portfolio built with **React.js**. It features smooth animations, 3D effects, and a professional layout to highlight my journey in software development.

## 🛠️ Tech Stack

- **Frontend**: React.js, React-Bootstrap, AOS (Animate on Scroll), React-Parallax-Tilt
- **Styling**: CSS3, Bootstrap 5
- **Animations**: Typewriter-effect, React-tsparticles
- **Icons**: React-Icons
- **Backend (Interest)**: Node.js, Express.js

## 📁 Features

- **Dynamic Hero Section**: Interactive particle background and typewriter effects.
- **Project Gallery**: Showcasing various projects with descriptions and live/GitHub links.
- **Skill Overview**: Visual representation of tech stack and tools.
- **Responsive Design**: Optimized for Desktop, Tablet, and Mobile devices.
- **Resume Integration**: Easy access to my professional resume.

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ahanas2004/portfolio.git
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Start the development server**:
   ```bash
   npm start
   ```
